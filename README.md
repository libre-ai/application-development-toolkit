# Libre AI Application Development Toolkit

[Français](README.fr.md)

Application developers often repeat the same interface and web integration work across products. This project explores shared components and testing helpers to make those interactions more consistent. Its focus is the everyday behavior users encounter across screens, from submitting a form to understanding an error.

## Intended uses

- Present consistent loading, success and error states across application screens.
- Give web adapters a common approach to handling requests and responses.
- Test a shared component within the application that uses it.

## Availability

This repository currently contains documentation only; no installable tool is available.
